# About
The Essential Capacities Landing Page project consists of an optimized html & tailwind css static SPA focussed on welcoming visitors to register for the upcoming Essential Capacities program.

The EC Landing page serves as the nexus for welcoming visitors into the circle of registered course participants. Visitors arrive from various channels (linked-in/substack/newsletter/BFCommons/referrals) to the landing page and are presented with content related to speaking to their aspirations/struggles, that the program promises to assist with. Visitors are able to register for the current course or subscribe to the waitlist for upcoming courses.

## Context

Currently program registration happens via context.org which is delivered via Wordpress and a legacy theme. While practical and effective for previous registrations, there are limitations as we step into a new phase for CI. Our current landing page endeavour is an attempt to build on previous work and support the current initiative to amplify the resonance of CI and the Bright Future Network.

## Project Vision

To create a light AI powered framework that assists CI  develop brand aligned landing pages that provide for high signal communication and clear pathways to help visitors discern their alignment and register for current and future CI programs.


## Mission
By crafting attuned invitations that meets the diverse needs/aspirations of people visiting the landing page, using high signal, meaningful design elements and information architecture, all of which is supported by performant, accessible and standards compliant web technology that allows for easy iteration, customisation and sensing into engagement patterns.

## Aims

-- Analytics/Feedback loops to explore resonance through iterative learning cycles and tiny experiments on messaging to diverse groups that would benefit from the Essential Capacities Program
-- fast loading, standards compliant, accessible code and visuals that facilitates high signal communication
-- a reusable AI assisted coding framework that allows for multiple versions of the landing page that can be atuned to the specific needs/aspirations of a diversity of visitors
